# 🌱 GreenHordeDefense - 植物大战僵尸·四季版

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow)](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript)
[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/zh-CN/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)](https://developer.mozilla.org/zh-CN/docs/Web/CSS)

一款基于 HTML5 开发的网页版植物大战僵尸游戏，创新性地加入了**四季关卡系统**，每个季节都有独特的游戏规则和视觉效果，为玩家带来全新的游戏体验。

---

## 🎮 游戏特色

- **四季关卡系统**：春天、夏天、秋天、冬天，每个季节都有独特的游戏规则和视觉效果
- **14 种植物**：向日葵、豌豆射手、寒冰射手、双发射手、火焰豌豆、西瓜投手、樱桃炸弹、火爆辣椒、坚果、窝瓜、毁灭菇、阳光菇、小喷菇、寒冰菇
- **6 种僵尸**：普通僵尸、路障僵尸、铁桶僵尸、橄榄球僵尸、读报僵尸、巨人僵尸
- **植物选择界面**：游戏开始前选择最多 6 种植物携带进入战场
- **波次挑战**：每关 5 波僵尸，难度逐渐递增，包含大波次
- **小推车机制**：每路配备小推车，自动触发碾压僵尸
- **音效系统**：背景音乐、僵尸嘶吼、豌豆射击、爆炸等音效
- **视觉特效**：四季动态特效（花朵摇曳、热浪、落叶、雪花）
- **暂停功能**：支持暂停游戏，暂停时可调节音量

## 🛠️ 技术栈

- **前端框架**：纯 HTML5 + CSS3 + JavaScript (ES6+)
- **渲染方式**：DOM + CSS 动画
- **音效系统**：Web Audio API
- **无需依赖**：纯原生开发，无需安装任何框架或构建工具

## 🚀 快速开始

### 本地运行

1. **克隆仓库**：
```bash
git clone https://github.com/Bistu-OSSDT-2026/GreenHordeDefense.git
```

2. **进入项目目录**：
```bash
cd GreenHordeDefense
```

3. **启动游戏**：
直接使用浏览器打开 `index.html` 即可开始游戏，无需任何依赖安装或构建步骤。

### 在线预览

访问 [GitHub Pages](https://pages.github.com/) 预览（如已配置）。

## 🎯 游戏玩法

1. **选择关卡**：从主菜单选择春、夏、秋、冬四个季节之一
2. **选择植物**：从 14 种植物中选择最多 6 种携带进入战场
3. **种植植物**：点击植物卡片后点击草坪格子进行种植
4. **收集阳光**：点击掉落的阳光收集资源
5. **抵御僵尸**：合理布局植物，阻止僵尸攻入家门
6. **使用道具**：点击铲子按钮可以铲掉已种植的植物

## 🍃 四季规则

| 季节 | 特点 |
|------|------|
| 🌱 春天 | 阳光菇生长加速，植物冷却缩短，射手伤害 +20%，坚果每秒回血 |
| ☀️ 夏天 | 火系伤害翻倍，僵尸攻击和移动速度翻倍 |
| 🍂 秋天 | 射手命中率 85%，灰烬范围缩小，僵尸移速 +10%，坚果落叶护盾 |
| ❄️ 冬天 | 阳光产出正常，植物冷却 +15%，僵尸移速和攻击 -20% |
